# Library Management System

A Java-based library management system developed to manage books and library members.

## Features

* Add and list books
* Add and list members
* Borrow books
* Return books
* Search for books using ISBN
* Search for members using Member ID
* Track borrowed books
* Console-based menu system

## Technologies

* Java
* Object-Oriented Programming (OOP)
* ArrayList / List
* Eclipse
* Git & GitHub

## Project Structure

* `Book.java` — Stores book information such as title, author, ISBN, and borrowing status.
* `Member.java` — Stores member information and borrowed books.
* `Library.java` — Manages books, members, borrowing, and returning.
* `Main.java` — Provides the console-based user interface.

## Purpose

This project was created to practice Java, object-oriented programming, collections, and basic Git/GitHub workflow.
